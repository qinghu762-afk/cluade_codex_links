# 可选：视频封面协作

此示例不影响联动 skill 用于其他任务，也不是原教程作者的原版 thumbnail skill。

Claude 定方案：读取用户指定的标题、口播 SRT 和参考图。缺素材先报告缺失项；与用户确认主张和逐字文案后，写唯一 thumbnail-prompt.md。派发只引用绝对契约路径，不能在消息中放第二份方案。

Codex 执行：先确认当前会话的实际工具定义包含原生 image_gen。不能把同名 skill、看图、HTML/SVG 或外部 API 当成原生生图能力。没有工具就写阻塞报告并回传，不自动切换付费方式或账号。确认工具可用后依契约生成，真实 JPEG 为 thumbnail.jpg（PNG 不能只改后缀）。

报告 thumbnail-report.md 必须包括实际路径、编码、尺寸、图片逐字文案、未通过/未检查项、实际重生成次数与原因。查看真实图片，检查 16:9、至少 1280×720、约 320×180 下可读性和契约禁止项。没有检查能力就写未检查，不能写通过。

完成或阻塞后实际执行任务 envelope 附带的 reply；Claude 收到结果执行 ack，再看文件和图片复审。通过给文件证据；未通过只指出一个最主要的具体问题，等用户确认返工。返工先修订唯一契约并归档旧图/报告，不能覆盖历史证据。最终仍由用户验收。
